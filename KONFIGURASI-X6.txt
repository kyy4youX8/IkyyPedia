IKYYPEDIAA X6

Fitur baru:
1. KOMPLAIN USER — menu "Komplain", admin bisa balas & ubah status
2. NOTIFIKASI TELEGRAM — order baru, top up pending, komplain baru
3. STATUS ORDER — badge status + tombol Refresh Status (sinkron ke IndoSMM)

----------------------------------------
SETUP TERMUX
----------------------------------------
cd ~
unzip IkyyPediaX6.zip
cd IkyyPediaX6
cp .env.example .env
nano .env

Isi wajib:
- INDOSMM_API_KEY
- ADMIN_USERNAME / ADMIN_PASSWORD
- SESSION_SECRET (min 32 karakter)
- MARKUP_PERCENT (contoh 10)

Isi opsional Telegram:
- TELEGRAM_BOT_TOKEN
- TELEGRAM_CHAT_ID

npm install
npm start

Buka: http://127.0.0.1:3000

----------------------------------------
CARA AMBIL TELEGRAM CHAT ID
----------------------------------------
1. Buka Telegram, cari @BotFather
2. /newbot → ikuti instruksi → dapat TOKEN
3. Start bot yang baru dibuat
4. Buka: https://api.telegram.org/botTOKENKAMU/getUpdates
5. Lihat "chat":{"id": 123456789 } → itu CHAT_ID
6. Masukkan ke .env

Di panel Admin ada tombol "Test Telegram" untuk cek koneksi.

----------------------------------------
ALUR
----------------------------------------
- User order → saldo lokal potong + notif Telegram + status pending
- User/Admin klik Refresh Status → ambil status terbaru dari IndoSMM
- User komplain → notif Telegram → admin balas di menu Admin
